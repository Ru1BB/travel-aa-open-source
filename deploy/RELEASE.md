# 版本功能说明

## 当前实现

- 多用户登录、独立旅程、上传者账单权限及管理后台。
- 微信与支付宝个人账单格式适配、日期筛选、合成示例和导入边界。
- 密码 6–128 字符、私有配置初始化管理员，不重置已有账号。
- 下方逐笔编辑/确认，批量类型/成员编辑与原子提交。
- 重新打开批量编辑恢复一致设置，混合设置保留各笔原值。
- 管理员增减成员，保留旧消费和快照；并发修改冲突检查。
- Excel 三表、历史结算快照、文件管理。
- 部署地址、证书名和内部端口参数化；公开模板不含个人服务器配置。

正常更新保留账号、数据库和文件。具体发布版本以部署包 REVISION 与实际当前源码链接为准；本文件不包含个人上线记录、服务器地址或凭据。
